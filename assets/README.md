# assets/

Эта папка содержит иконки и графику, которые скачиваются автоматически при сборке.

Файлы генерируются скриптами сборки и не хранятся в репозитории (см. .gitignore):
- icon.png       — скачивается с CDN EPGMaster
- icon.icns      — конвертируется из icon.png (macOS)
- icon.ico       — для Windows (опционально)
- dmg-bg.png     — фон установщика macOS DMG
